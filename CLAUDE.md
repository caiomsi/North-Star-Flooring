# CLAUDE.md

This file provides guidance to Claude Code when working in this repository.

## What this is

North Star Flooring & Construction, a **real client** (flooring/construction contractor,
South Salt Lake, UT, English). Static HTML/CSS/JS, no build step. See the root
`../CLAUDE.md` for shared conventions (preview/deploy commands, SEO expectations,
image guidelines).

## Structure

`index.html` (single page) at root, `css/style.css`, `js/main.js`, photos in `images/`
(see `images/README.md`; originals live in git-ignored `images/source/`), plus
`404.html`, `robots.txt`, `sitemap.xml`. `research.md` holds the audit of the client's
old site and every verified/UNKNOWN fact: consult it before writing any claim.
Hosted on GitHub Pages at `caiomsi.github.io/North-Star-Flooring`; the client's domain
`thenorthstarflooring.com` will be pointed here after approval.

## Design language

See `DESIGN.md` ("True North": midnight navy + champagne gold, Cormorant Garamond /
Marcellus SC / Hanken Grotesk, the `.compass` section-heading device). Tokens live at the
top of `css/style.css`. The logo is white-text and only works on dark backgrounds.
Project photos are small (355-740px): frame them at or below native size.
